# Customer Data Privacy Review & PII Masking

## Overview

A hands-on privacy training project using synthetic customer data generated with Mockaroo.

## What I Did

* Identified direct and indirect PII, including names, emails, phone numbers, IP addresses, and customer IDs.
* Assessed potential privacy risks from individual fields and combined identifiers.
* Applied email, phone number, and IPv4 masking using Excel formulas.
* Documented a role-based Access Control policy based on the principle of least privilege.
* Validated the masked outputs.

## Tools

Microsoft Excel | Mockaroo

## Note

This project uses synthetic data for educational purposes. Access Control was documented as a recommendation; technical permissions were not implemented. Masking reduces exposure but does not guarantee anonymization.
